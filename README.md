### Proyecto desarrollado por los estudiantes de ingeniería en sistemas de la Universidad UMG de Guatemala. 

## Problema a resolver:
### Muchos jóvenes tienen dificultades para elegir carrera universitaria o técnica porque no cuentan con suficiente orientación personalizada ni información clara sobre el mercado laboral.

## Uso de IA:

 - GPT: Entrevistas simuladas y tests personalizados que identifican habilidades blandas y técnicas.
 - Gemini: Análisis predictivo de tendencias laborales y demanda en distintas profesiones.

## flujo MCP:

- Usuario completa cuestionario interactivo.
- MCP conecta con GPT para generar un perfil vocacional y posibles carreras recomendadas.
- Gemini predice oportunidades laborales según datos globales.

# Stack Final del Proyecto

- Frontend: React + Tailwind CSS + Spline UI 3D.
- Backend: Node.js (con Express.js).
- Base de Datos: PostgreSQL.
- IA APIs: *GPT-4o mini* para chat y geneación de perfil vocacional, *Gemini* Free Tier para oportunidades laborales.
### Rutas del proyecto: 

/vocacional-app

│── /frontend       # React + Tailwind + Spline.

│── /backend        # Node.js + Express.

│── /docs           # Documentación, diagramas, MCP.
